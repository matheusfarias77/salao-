# ✨ Emilia Beauty Coiffeur - Landing Page de Alto Padrão

Landing page profissional, responsiva e moderna desenvolvida para o salão de beleza de alto padrão **Emilia Beauty Coiffeur**, localizado em Realengo, Rio de Janeiro - RJ.

---

## 🌟 Recursos e Destaques

- **Identidade Visual Luxuosa**: Fundo preto grafite (`#0A0A0A`), tipografia serifada de alto padrão (*Playfair Display*) e detalhes em dourado metálico (*Gold Luxe*).
- **Header Inteligente**: Navegação fluida, logo autêntica e botão de chamada para ação com efeito translúcido (*backdrop blur*).
- **Hero Section Impactante**: Dobra principal elegante com sobreposição aveludada, badges de autoridade, pilares de atendimento (*Beleza • Estética • Bem-estar*) e duplo CTA.
- **Nossos Serviços (Cards com Lift)**: Vitrine categorizada em *Beleza*, *Estética Capilar* e *Bem-estar*, com tempo estimado, itens inclusos e botão de agendamento que pré-seleciona o serviço no formulário.
- **Galeria de Trabalhos (Inspiração Instagram)**: Grade no estilo alvenaria (*masonry*) com transformações em loiros, morenas iluminadas e cortes, acompanhada de contador de curtidas, visualizador em modal (*lightbox*) e convite para seguir `@coiffeursalaodebeleza`.
- **Formulário de Pré-Agendamento Flutuante**: Card em vidro fumê (*glassmorphism*) com máscara automática de telefone brasileiro, restrição inteligente de dias (terça a sábado) e confirmação automática integrada ao **WhatsApp**.
- **Diferenciais VIP & Prova Social**: Apresentação dos pilares de atendimento (Kérastase, L'Oréal, ambiente climatizado, café gourmet/espumante) e avaliações 5 estrelas.
- **Rodapé & Localização**: Endereço na Rua Capitão Teixeira em Realengo, horários de atendimento, rotas no Google Maps e botão flutuante persistente do WhatsApp.

---

## 🚀 Tecnologias Utilizadas

- **React 18**
- **Vite** (Build ultra-rápido)
- **Tailwind CSS** (Estilização modular e responsiva)
- **Lucide React** (Ícones vetoriais modernos)

---

## 💻 Como Rodar o Projeto Localmente

1. **Instale as dependências**:
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   Acesse a URL exibida no terminal (geralmente `http://localhost:3000`).

3. **Gerar a versão de produção**:
   ```bash
   npm run build
   ```

## ☁️ Como Exportar para GitHub e Vercel

### 1. Enviar para o GitHub:
```bash
git init

git commit -m "feat: landing page emilia beauty coiffeur completa"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/emilia-beauty-coiffeur.git
```

### 2. Publicar na Vercel:
1. Acesse [vercel.com](https://vercel.com) e faça login com seu GitHub.
2. Clique em **"Add New..."** > **"Project"**.
3. Selecione o repositório `emilia-beauty-coiffeur`.
4. O framework **Vite** será detectado automaticamente.
5. Clique em **"Deploy"**. Em menos de 1 minuto seu site estará online com certificado SSL gratuito!
